# Cassandra 学习文档

本目录用于记录从 Java 后端开发视角学习 Cassandra，并结合 ThingsBoard 3.6-release 源码理解其时序存储设计。

入口文档：

- [通过 Cassandra 学习 ThingsBoard 架构设计](./thingsboard-cassandra-learning-guide.md)

阅读建议：

1. 先读第 0-3 章，建立 Cassandra 与 PostgreSQL/MySQL 的差异。
2. 再读第 5-8 章，理解写入、读取、分区、故障恢复和排障。
3. 最后重点读第 9-10 章，对照本地源码阅读 ThingsBoard Cassandra DAO。
